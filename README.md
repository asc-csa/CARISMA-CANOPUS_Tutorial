# Visualisation des données CARISMA/CANOPUS - Un tutoriel

> **Description brève :**  
> Ce tutoriel se concentre sur l'extraction et la visualisation des données magnétométriques CARISMA et données riométriques CANOPUS.

## À propos

**Visualisation des données CARISMA/CANOPUS - Un tutoriel** couvre :

- Extraction et visualisation des données des magnétomètres CARISMA
- Extraction et visualisation des données des riomètres CANOPUS
- Un aperçu des produits dérivés des magnétomètres CARISMA

*Ce tutoriel est fourni à des fins pédagogiques et expérimentales.*

## Prérequis

- Python 3.11 ou plus récent
- Jupyter Notebook ou Jupyter Lab
- Bibliothèques Python : pathlib, re, requests, numpy, matplotlib, pandas
- Connexion Internet

## Démarrage rapide

1. 📦 **Cloner le dépôt**
   ```bash
   git clone https://github.com/asc-csa/CARISMA-CANOPUS_Tutorial.git
   cd CARISMA-CANOPUS_Tutorial
   ```
2. 🐍 **Créer un environnement**
   ```bash
   # Avec virtualenv
   python -m venv env
   source env/bin/activate

   # Ou avec conda
   conda create -n carisma_env python=3.11
   conda activate carisma_env
   ```
3. 🚀 **Lancer le tutoriel**
   ```bash
   jupyter notebook
   ```

## Astuces & Conseils

- **Données CARISMA :** Les données sont disponibles via l'ASC et le site web de CARISMA.
- **Données CANOPUS :** Les données sont disponibles via l'ASC.

# Visualizing CARISMA/CANOPUS data - A Tutorial

> **Brief description:**  
> This tutorial focuses on extracting and visualizing CARISMA magnetometer data and CANOPUS riometer data. 

## About

**Visualizing CARISMA/CANOPUS data - A Tutorial** is a tutorial that focuses on downloading and analyzing CARISMA/CANOPUS data. It covers:

- Data extraction and visualization of CARISMA magnetometer data
- Data extraction and visualization of CANOPUS riometer data
- An overview of derived CARISMA magnetometer products


*This tutorial is provided for educational and experimental purposes.*

## Prerequisites

- Python 3.11 or newer
- Jupyter Notebook or Jupyter Lab
- Python libraries: pathlib, re, requests, numpy, matplotlib, pandas
- Internet connection

## Quick Start

1. 📦 **Clone the repo**
   ```bash
   git clone https://github.com/asc-csa/CARISMA-CANOPUS_Tutorial.git
   cd CARISMA-CANOPUS_Tutorial
   ```
2. 🐍 **Create environment**
   ```bash
   # Using virtualenv
   python -m venv env
   source env/bin/activate

   # Or using conda
   conda create -n carisma_env python=3.11
   conda activate carisma_env
   ```
3. 🚀 **Run the tutorial**
   ```bash
   jupyter notebook
   ```

## Tips & Tricks

- **CARISMA Data:** Data is available through the CSA and the CARISMA website.
- **CANOPUS Data:** Data is available through the CSA.
